## Existing contract

An encyclopedia is the presentation and authorized exploration of the SAME world objects, not a fourth database. Node = semantic meaning, Canvas = authored presentation, Display = compiled audience-authorized reading. An eligible identity can exist before it has an article; a private or unpublished object must not leak via reader navigation, directory, counts, snippets, image targets or inferred references. Existing accepted ENT-01, CAN-01/02, LNK-01, DSC-01, QRY-01/02/03, INV-13/15 and AT-17–25/34 govern implementation. #72 covers bounded ontology, #68 maps, #70 conditional workflow readiness; no extra runtime engine or universal schema editor.

## Present functional coverage

- Stable world/entry identity, versioned layout persistence and current release flag; general entry editor opens from person/event/relationship inspectors and typed search results, including source/claim and off-scene objects.
- 22 ObjectKindFilter values, 24 NetworkKind values, four curated semantic profiles; nine built-in v1 Canvas templates: Blank, Character, Family, Organization, Event, Conflict, Location, Genealogy, Source. Custom templates are persisted and pinned, instantiated with new presentation IDs and supported rebindings; they do not clone canonical entities.
- Layout ElementContent currently Stack/Panel/Grid, template/custom template, Text, ObjectLink, Image, Query/SavedQuery, FamilyTable/NetworkTable/ImpactTable, PublishedReferences/PublishedStatements. Text editor uses textarea; public-reader Text is p.textContent. Not yet the full normative heading/rich-text/component registry.
- Explicit object-link blocks have stable target IDs, captions and audience. Image hotspots support scoped reference targets and alternative text. Author backlinks, semantic backlinks and approved mentions are separate. Ghost/mention proposal approval must never by itself assert a fact.
- Public search uses trigram FTS candidates for terms of at least three characters, bounded fallback for short terms, caption and dynamic dependencies then authorized compilation. Returns matching blocks with entry and element IDs, not ranked article results. Current main/latest revision; fictional day filters eligibility. Local reader opens authorized linked page, rechecks release at each hop; back history bounded to 64 IDs. 
- Author-only query/family/network/impact blocks intentionally rejected if published to less restrictive scope; published references/statements are dedicated permitted projections, not arbitrary query exposure. Existing tests include reparent/pins, public index revocation, caption reauthorization, private-subtree suppression, image archive and linked navigation. This is partial AT coverage, not full publication security certification.
- PNG import/assets, hotspots, archive restore and integrity checks implemented. No polished export/site or stand-alone encyclopedia host established by reviewed code.

## Domain coverage without ontology sprawl

Use existing Person, FamilyHouse/Household, Organization/Faction/Office/Title, Place, HistoricalEvent, Conflict/ConflictIssue/ConflictPhase, Asset, Concept, Population, Source, Claim, Relationship and other addressable facts as appropriate. A kingdom, species, language, religion, custom, currency, technology, food, mineral, festival, law, artifact or era can have a page without requiring its own Rust object type. Only use typed classifications and relationship semantics when approved and validated. Current profiles Culture/Language/Material/Technology are not a full taxonomy for every domain. Article grouping/category/collection is a presentation or explicitly governed semantic reference, not automatic canonical classification; verify existing mechanisms first. Suggested domain-specific article templates can start as custom templates, not new schema. Avoid claiming species/ecology/economics simulation exists.

## Proposed experience (not implemented)

Encyclopedia is the coherent Canvas/Display experience, not a fourth canonical layer. Author world explorer lists eligible entries, filters by existing kind/profile and shows verified article state, opens full writing/composition surface. Reader home presents authorized topical navigation and search. Article uses optional authorized title and kind, overview, structured text headings, infobox, links, citations, context-aware related entries, and optional typed panels/timeline/map/genealogy that are only enabled once their data projection supports audience. Navigation keeps selected context and safe reference history. Visual identity from UI-Visual-Design-Audit: quiet atlas/editorial layout, comfortable reading width, restrained imagery, clear source/claim distinction. Never invent facts to fill a template. Empty section can be omitted explicitly, unknown must remain unknown. Maintain plain-text fallback and keyboard navigation.
