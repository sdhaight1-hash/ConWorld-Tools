# ADR-014 — Independent editorial release selection

**Status:** Accepted architectural direction, implementation readiness pending. **Date:** 2026-11-22. [#77](https://github.com/sdhaight1-hash/ConWorld-Tools/issues/77), [owner approval](https://github.com/sdhaight1-hash/ConWorld-Tools/issues/76#issuecomment-7079741458), [evolution specification](../Architectural-Evolutions/independent-editorial-draft-and-publication-lifecycle.md).

The current combined layout/version publication flag couples authored save with release. Preserve its semantics until a verified migration. Approved delta: one entry may have a newer saved author draft and separate current explicitly released immutable layout version. Editing/restoring draft does not alter release. Publishing selects validated draft atomically and updates derived reader indices; withdrawal clears release and current reader access. Historical author restore appends new revision, never revives permissions. Maintain Rust scope authority and current release reauthorization; unsupported branch/perspective paths fail closed. Existing #4/#5/#8/#10 owners handle shared integration. Resolve exact time/pin semantics for bound components, migration and wire types at A1. This refines the publication selection assumption in 06/07/08 and ADR-010, not the underlying ontology or the existing phase acceptance requirements. User approval is not readiness or verified implementation. All A1–A5 outstanding beyond scope approval. No runtime change here.
