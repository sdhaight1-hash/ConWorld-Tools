# ADR-013 — One historical spatial authority, procedural proposals and derived cartography

**Status:** Accepted design direction, 2026-11-21 local / 2026-11-22 UTC; production verification pending. Owner approved reconciliation of research #65 and #66. Baseline main [5d29ff2](https://github.com/sdhaight1-hash/ConWorld-Tools/tree/5d29ff24146c6b30a12558e1444404f756893432), schema 33 before open #62/#63. No code changes.

## Context and evidence
[NestedLocations](../Research-Studies/nested-locations.md) identifies missing implemented Place despite normative registry design, proposes typed temporal adjacency and optional geometry, reports isolated SQLite 9 assertions and synthetic 50k tree. [Vector cartography](../Research-Studies/procedural-vector-cartography.md) reports synthetic Chromium geometry/determinism/history/drill-down tests and SVG/Canvas2D microbenchmarks, archived screenshot, limitations. Neither proves native runtime, full permissions, real branch integration or production GIS performance. Both agree on canonical facts vs derived presentation; reconcile their differing sequencing by explicit semantic-only, exact/schematic then candidate slices. No external code or new dependency adopted.

## Decisions
- D-017: stable world Place and reified role-typed, temporal/lens-scoped adjacency using existing revision, branch and evidence authority. Frames and geometry optional and independently versioned. Strict hierarchy cycles invalid only in co-effective intervals; other spatial relations independent.
- D-018: exact authored, schematic and candidate modes distinctly marked. Candidate generation is bounded, deterministic, lock-aware, not canon until explicit validated author transaction. Existing assets/effects/ownership/movement reused; maps never authoritative copies.
- D-019: scoped QuerySpec → authorized map composition → immutable MapScene; authorization before *all* derivations including secret anchor influence, labels and extents. Reuse Node/Canvas/Display, existing publication policy and archive.
- D-020: bounded SVG first and accessible list, Canvas2D for larger/fallback when measured, optional existing wgpu acceleration only with evidence. Versioned typed map recipes, theme/symbol assets, no second database/renderer truth. Local frames first; advanced GIS/geodetic, tiles and urban/interior solvers deferred.

Alternatives rejected: single fixed parent; canonical closure/materialized path; geometry-first mandatory GIS; universal Earth coordinates; independent graph/GIS DB; SVG document as canonical world; generator always canonical; GPU-first mandatory rendering. They conflict with identity/history, partial data, policy, offline support or simplicity. Derived closure/topology/R*Tree/tiles may be evaluated rather than forbidden.
