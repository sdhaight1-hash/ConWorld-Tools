# Phase 4 — Custom versioned Canvas template library

Tracks #5 and #8. Schema 31 named author-only reusable template versions snapshot an existing saved page's authored presentation, not canonical records or evaluated rows. Exact revision pins persist in CustomTemplate elements. Instantiation regenerates element IDs, wraps in private scope while retaining original ancestry, rebinds supported self-bound family/network/impact/reference/inline query components to destination and preserves explicit saved-query versions. The native studio creates/revises and lists templates, Canvas loads and inserts them. Existing instances never auto-upgrade. Internal drag/drop uses the same bounded privacy-preserving move operation as keyboard controls. Regression covers version pinning, fresh IDs, self-reference rebinding, unchanged earlier instance and reader denial. Stacked on #59, verification pending.
