# Writable branch-local historical metadata

Schema 34 shares one recursive revision/day lineage query for accepted parentage, institutional facts and persisted causal traversal. A fact's origin is its creating revision's branch. Local insertions and withdrawal overlays are explicit commands, never updates to another branch's fact row. Legacy withdrawals remain readable. Child validation includes visible inherited records and scheduled local intervals; no before-fork writes; ancestor revision and date are frozen. Scope author only. Conflict/overlap/cycle checks reused. Regression covers parent, sibling, nested fork, prior revision, pre-fork history and FK integrity. Native request contracts accept optional branch ID; main-only discovery/templates unchanged. Verification pending.
