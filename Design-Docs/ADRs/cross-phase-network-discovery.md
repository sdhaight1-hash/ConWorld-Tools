## Integrated Canvas and publication

NetworkTable reads dated author-only fact records against the same selected world and revision. Character, organization, family, event and conflict templates get a live network component. PublishedReferences is a restricted reader-capable dynamic component: it reads only the current public explicit-backlink projection, not semantic network facts, raw registry labels, or hidden counts. It uses the same backlink walker within the current read transaction, and withdraws a source immediately on the next read without rewriting the destination. Historical author previews return an empty public reference component rather than replaying revoked publications. Dynamic results are deliberately excluded from static FTS and authored-link indexing to prevent stale or recursive dependency artifacts. Tree mode includes bounded 32-step local undo/redo; saves are still revisioned by Rust. One cross-phase regression covers canonical kind query, membership overlap, causal cycle, draft promotion, historical replay, withdrawal and public dynamic reference visibility. Browser regression covers native command contract and screenshot configuration. CI pending.
