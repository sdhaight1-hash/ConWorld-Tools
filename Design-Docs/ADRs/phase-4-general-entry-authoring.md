# Phase 4 — General entry authoring access

Tracks #5 and #4, ENT-01, INV-01/13, AT-17/20 (partial). The existing persistent page editor is not character-specific at the Rust boundary: it accepts a stable object identity in the selected historical view. Expose it directly from event and relationship inspectors, and from any typed author query result (including sources, claims and off-scene objects). Use one editor, layout identity and publication compiler. Display the stable entry ID and known label; offer current graph event, relationship, person and definition IDs in the same link picker without inferring facts or copying records. Search-result opening also works when the scene budget is exceeded. Preserve selected author revision and day, disable saves on pinned views, and do not turn a non-graph target into a graph selection after save.

Existing flat supported layout shape remains unchanged. This is a general entry access slice, not the full composable Canvas/template editor. No migration, IPC or new authority. Playwright mock-native test covers event save/reopen, source entry authoring from queries, revision pinning and typed layout identity. CI captures the source editor with the standard Development-Screenshots filename; no screenshot or green result claimed before the run.
