## Second slice — contextual documented connections

The entry shell now reuses the existing reference picker to select compatible outgoing targets and evidence. Predicate options are an explicit bounded UI subset of the native endpoint checks in store/network.rs: membership, marriage, office/title, ownership, population, faction/issue, typed location and physical/admin containment; location role and conflict stance are constrained. Native Rust remains authoritative for dates, source validity, overlapping exclusive roles, cycles and provenance. Specialized causality, succession, profile-specific and correction workflows remain in existing tools. Refactor shares picker result handling and entry context, not a second source of truth. The editor records a sourced fact at the selected day and reloads the selected entry's Connections view. Draft guard also blocks navigation during that command. Existing native commands and schema unchanged. Expanded browser test verifies exact connection payload and next revision, not a substitute for real IPC and native author scenarios. Both slices await exact-head CI.

## Mutation/navigation hardening

The directory creation and contextual network command now share the connected in-flight guard with the article editor. Disable mutation input controls during invocation, prevent navigation that would discard a newly opened draft, reopen only in the same world/day after a strictly newer loaded revision, and distinguish a committed write from a failed refresh. Delayed-create browser check ensures Back cannot replace the current entry during creation. The guard status is generic to entry changes, not a claim that semantic facts are page data.

## Reader search refactor

World-wide search now budgets distinct authorized articles through the original native query/candidate/compile path; only one matching element is returned per article. Existing block search in a single page and the prior block-result API remain intact. Pagination remains bounded/refine-required (not a new completion claim). The reader reloads current publication, then focuses the authorized matching element if still present; otherwise it shows an explicit changed/unavailable notice without exposing author labels or hidden text. Regression covers 75 matches in one article, second article inclusion, hidden and unreleased content, revocation, exact authorized anchor, and original block semantics. No schema change or publication lifecycle change.

## Family integration and full source review disposition

The family editor is now available directly from a Person entry (including when the graph is over budget). Both parentage and optional fictional-inheritance relative selection reuse the common bounded reference picker with an author-only person-kind filter; the existing accessible selects and nearby options remain. Preserve biological/legal/adoptive distinctions and source/rationale-bearing temporal validation. Guard in-flight family writes exactly like article/connection writes; refresh and reopen the family tool at the new revision. No automatic inference of parents, family/house membership or genetics. Expanded mock-native task exercises a person outside the loaded scene selecting and recording a parent from the historical search service, then continuing the same World Bible workflow. Parentage and network facts remain separate specialized commands.
