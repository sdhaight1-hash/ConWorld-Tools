## Bounded Boolean semantic seek (AE-05/06/08)

The candidate extends the same query executor to nested AND/OR/NOT over classification, label and kind leaves, only when a positive classification candidate union is sufficient. AND can select one bounded arm; OR requires a bounded arm in every alternative; NOT cannot establish a universe. Selection traverses every child within the existing predicate depth/node limits. Before reading candidates, validate every descriptor (even under negation, absent alternatives or unused anchors); an absent descriptor is false, not an empty whole OR. The SQL uses fixed allowlisted column identifiers and bound values, exact object-level predicates are reevaluated after canonical point/assignment resolution. Candidate pairs remain capped at 2,000; unsupported shapes fall back without changing their existing work/error policies. Dense unions and selective residuals still require measurement. No schema changes, public query expansion or alternate truth store. Regression additions cover nested OR/AND/NOT, same-label order, historical rename order, missing descriptor alternatives, invalid negated descriptor and canceled-page recovery.
