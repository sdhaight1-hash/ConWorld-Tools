## 1. Problem and accepted scope

The original roadmap specifies Place identity, event sites, location templates, MapView/ConflictMap and enhanced geography broadly, but not the integrated multi-lens temporal containment, independent frames and procedural construction of vector maps from partial location data. #68 adds that extension, without duplicating ordinary Place, search or existing Canvas responsibilities. An author can create places before geography is known, associate people/institutions/events/assets, explore a historical atlas and generate constrained draft geometry without inventing authoritative history.

V1 includes world-scoped stable Place extensions, versioned types, sourced exact temporal containment and placement, multiple explicit lenses, optional local point/line/polygon/multipolygon geometry with holes, historical traversal and saved query integration, exact and explicitly schematic maps, nested semantic navigation, versioned recipes/styles/symbols, accessible scoped display and safe vector export, a bounded planar draft generator with fixed locks and explicit validated promotion. Existing media can be an underlay, not canonical geometry. Unknown coordinates stay absent.

Deferred: full GIS/CAD, procedural planetary terrain/tectonics, advanced street/parcel/interior solvers, mandatory geodetic projection/tiles/GPU or remote maps, full routing and NPC integration. No new roadmap phase. No specific dependency/library/schema number endorsed merely by approving this feature. #66's remaining experimental criteria must be completed or explicitly deferred by the owner before final feature closure.

## 2. User workflows and UX

- Author creates Valley, Town, Estate, Manor and Study without coordinates. Selects physical lens or administrative hierarchy; same Town can be a member of different compatible hierarchies without duplicate identities. Chooses a historical day, branch and author revision, sees sourced relationships and records a dated move. A person's residence and event site resolve to the chosen Place independently of asset ownership or control.
- Node exposes a location explorer, kind/type/name discovery, path/role queries, explicit draft identity review, stable selection, evidence and dated editing. Unknown names remain candidates. Show multiple parents, invalid intervals, stale revision, cycle errors and traversal limits; no automatic semantic mutation from text matches.
- Canvas binds MapSpec to Place, frame, lens, typed query and pinned theme. Exact mode uses authored geometry; schematic mode is labeled not to scale and includes unplaced locations in a list. Select town, estate or floor to drill down even when no transform exists. A map may contain mixed origin statuses clearly labeled. Style changes never change world facts. Generate a draft from visible constraints with seed, algorithm version and locks; show conflict/unsatisfied/unknown report; reject or explicitly accept after preview.
- Display renders only authorized released features, navigation and accessible list with same view context. No author-only data in front-end state or export. Date/branch/perspective change re-evaluates consistent snapshots. No unsupported map distance, hidden path inference or secret anchor influence. Keyboard and screen reader routes available. Loading, empty/unplaced, unavailable/denied (indistinguishable where required), unsupported frame, malformed input and cancellation are explicit states. No public projection of incomplete draft in v1.

## 3. Architecture and integration

Use existing Rust atlas-store registry, transaction/revision/branch overlays, typed fact/provenance and query machinery; evaluate narrow typed table only if existing fact contract cannot meet gates. Logical types and predicate composition rules in 13 are normative for #68. Strict physical/admin edges are irreflexive and free of co-effective cycles per compatible lens. Interval traversal intersects edges; branch resolution freezes inherited revision. Ownership retains Asset semantics, historical changes explicit event effects; placement, jurisdiction, claim and control are distinct. Mobile interior keeps identity as vessel moves, unknown transforms forbid geometric comparison. Claims/uncertainty separate from exact canonical fact; no unsupported inference or duplicate truth.

Store optional frames and versioned geometry separately from Place identity using shared branch/revision and provenance. Derive MapScene from authorized query snapshot; stable references and feature-level origin, typed geometry/style, bounds, labels, links, legends and permitted omissions. Save versioned MapSpec and LayerSpec pins, seed/locks/overrides, not copied facts. SVG-first bounded scene and safe allowlist export; Canvas2D fallback as needed, optional wgpu after measured target evidence. Reuse existing Tauri typed IPC and HTML/CSS/TS studio interfaces; no separate map database, mandatory GIS or standalone studio. Exact geometry and schematic views precede candidate generation.

Extend QuerySpec with WithinPlace, LocatedIn, contextual PlaceName and spatial predicate/features as applicable. Maintain bounded deterministic pagination, cancellation, source/branch/date/access context, saved bindings, indexed names/backlinks and dependency invalidation (prior/new ancestors, placements, frame, geometry, recipe, policy); spatial indexes derived only, bbox candidates require exact predicate. Ghost/name/image references follow review rules. Author validation sees full canonical graph; reader query filters nodes, facts, sources and frames before traversal or composition. Filter before procedural constraints, label placement, extent, legend, aggregates, caching, hit IDs, SVG export and asset access. Public noninterference tests compare inputs with/without hidden records. Redact or withhold raster/geometry embedding secret features; never rely on CSS hiding. Unsupported projection denied.

## 5. Migration, rollback and risks

Baseline c48fadc schema 36 (independent merges #62/#63); premature #67 candidate 31038560 is unmerged and not an accepted implementation. The actual next schema number must match reviewed current baseline. Migration atomic, backup before upgrade, preserve stable IDs, fact/provenance and revision/fork history, verify foreign keys and reopen; unknown newer schemas rejected by older binaries. No automatic downgrade; rollback application code via reviewed revert and recover through verified pre-upgrade backup to a new destination if schema incompatible. Archive restores frame, geometry, recipes/pins, local assets and hashes; derived caches rebuilt and compared, not trusted as authority. Public release separate from full archive.

Risks: temporal cycles, multiple lenses and wrong-kind edges (interval mutation validation); branch drift (freeze/withdrawal tests); secret input inference (pre-derivation policy and adversarial tests); invalid polygons/frame mixing (finite bounds, exact geometry and transform validation); excessive work (depth/expansion/vertex/byte/deadline limits and profiling); nondeterministic or infeasible drafts (stable seed, locks, explicit failure); desktop regression (exact-head native CI and evidence). Do not adopt external libraries until exact version/license and platform compatibility reviewed. Research benchmark numbers are not an app SLA.

## 6. Alternatives and decisions

Manual raster maps and ordinary Place cover existing roadmap but cannot generate query-driven maps. Fixed single-parent trees cannot represent concurrent lenses. Geometry-first GIS forces authors to supply coordinates; separate graph/GIS DB and SVG-as-authority duplicate history and permissions. The accepted choice is typed temporal adjacency, optional geometry and one derived scene representation. A bounded planar candidate generator is enough for v1; advanced terrain, city and interior algorithms remain deferred. No universal renderer cutoff inferred from synthetic browser measurements.
